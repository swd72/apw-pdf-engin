## Should fix (MEDIUM)

Correctness:
- M1 `pdf/writer.ts:105-151` ToUnicode wrong for tall consonant + sara am (ปำ ฝำ ฟำ) — shifted nikhahit glyph breaks the collapse; first-wins mapping then corrupts later words (ปิ้ extracts as ปิำ). Use `/ActualText` spans for clusters whose glyph count ≠ codepoint count.
- M2 `writer.ts:69` `saraAmGid = saraAaGid + 1` guess — look up U+0E33 in cmap; skip collapse if absent.
- M3 `flow.ts:474-486` signature pull-back: can leave a 1-line orphan; nothing pulled when previous block is a table; unbounded repeat if signature+3 lines > page. Keep ≥2 lines behind, pull-once guard.
- M4 `flow.ts:400-409` keepWithNext chains (A→B→C) not honoured.
- M5 `align.ts:117-131` default tabs measured from wrong origin; no implicit tab at hanging indent (Word does) — `1.⇥text` with hanging indent misaligns ~7.65pt.
- M6 `align.ts:357-362` distributed weight counted after numeric `fill`/`pageNumber` items but no extra applied → line ends short.
- M7 `columns.ts:37-92` all-right-aligned columns silently rewritten (external-letter hack in generic layout) — move behind explicit option.

Templates (from visual check of goldens):
- T1 Leave forms: `(ลงชื่อ)` has no dotted signature line and no room to sign — official form is `(ลงชื่อ) ..............................` above `(name)`.
- T2 Leave forms: missing `ผู้ตรวจสอบ` label and `วันที่ ......` lines under checker/supervisor/approver blocks.
- T3 External letter body paragraphs have `spaceBefore: 6pt`; manual §4.2.5 says other text is Single, and memo body has none. Make it a template option defaulting to 0.

Security:
- M8 `providers.ts:154-161` containment is lexical (symlinks/junctions followed); `baseDir` defaults to `process.cwd()` and MCP passes none — require explicit `imageBaseDir` in MCP; realpath both sides; stat before read.
- M9 MCP `tools.ts:165-175` and providers echo raw fs errors with absolute paths — generic messages for non-ApwPdfError, log detail to stderr.
- M10 Unbounded custom page width/height and font size (huge canvas in `render_page_png`, millions of lines) — clamp page ≤ 5000pt, min font size, cap raster pixels.
- M11 `save_template` / template/example size uncapped, silent overwrite; data cap counts chars not bytes.
- M12 React `fetch-providers.ts:82-95` same-origin check bypassed by `//evil.com` and `HTTPS://`; no size cap/timeout — resolve with `new URL(x, location.href)` and compare origin.
- M13 Express example: default error handler leaks stacks, raw `err.message` on 500, `listen` binds all interfaces while logging 127.0.0.1, no rate limit.
